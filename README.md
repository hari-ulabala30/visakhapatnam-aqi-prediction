# Visakhapatnam AQI Frontend v2

This is a UI-only upgrade for the existing Visakhapatnam AQI Prediction project.

## Files
- `index.html` — redesigned dashboard UI
- `styles.css` — responsive visual design, dark mode, cards, layout and animations
- `app.js` — dashboard rendering, charts, filters and interactions

## Backend
No backend changes are required. Keep the existing `aqi_server.py` and Python project files unchanged.

## Run
From the folder containing `aqi_server.py` and these frontend files:

```powershell
python aqi_server.py
```

Open:

```text
http://127.0.0.1:5000
```
